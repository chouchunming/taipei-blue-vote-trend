## 上游來源

- `source_manifest.json`：2000–2024 臺北市總統選舉資料的逐檔 URL、SHA-256、
  版本與中選會上游授權。
- `mayor_source_manifest.json`：2002–2022 臺北市長選舉資料的逐檔 URL、
  SHA-256、版本與中選會上游授權。
- `age_source_manifest.json`：2023 年 12 月戶政司村里單一年齡人口 API 的
  資料集頁面、API URL、範圍、位元組數與 SHA-256。
